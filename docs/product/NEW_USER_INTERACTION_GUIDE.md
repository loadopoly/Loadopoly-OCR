# New User Interaction Guide

This guide details the exact process flows a new user makes when first discovering and interacting with the GeoGraph OCR system.

## Flow 1: Registration and Discovery
1. **Landing Page:** User explores the value proposition, features, and pricing.
2. **Onboarding Initialization:** User clicks "Try Free" or "Get Started".
3. **Onboarding Wizard:**
   - Slide 1: Welcome & Value
   - Slide 2: Knowledge Graph intro
   - Slide 3: GIS features
   - Slide 4: Cloud Sync & Privacy
   - Final: Complete setup.
4. **First view:** Empty Dashboard state.

## Flow 2: Setting up preferences
1. **Settings Tab:** Navigate to Settings using the sidebar.
2. **Configure API Key:** User enters Gemini API Key (simulate test key entry).
3. **Save preferences:** Ensure storage is synced.

## Flow 3: Asset Upload & Knowledge Extraction
1. **Quick Processing Tab:** Navigate to batch ingestion.
2. **Uploading Document:** Simulate upload of a sample document.
3. **Structured DB Validation:** Check Structured DB for successful extractions.

## Flow 4: Analytical Tools & Visualization
1. **Assets & Bundles:** Switch view to see cards.
2. **Knowledge Graph:** View the global and single asset network.
3. **The Journey:** Switch and click 'Start Adventure' in Knowledge Graph.

## Flow 5: Extension Engagement
1. **3D World / Spatial Map:** Open the extension and verify rendering.
